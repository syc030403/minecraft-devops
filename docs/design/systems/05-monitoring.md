# 05. 모니터링 (`area:monitoring`)

서버 상태 확인, 알림, 로그.

## 규칙
- [아이디어] 서버 다운·백업 실패·디스크 부족을 알린다.
- [아이디어] 에반게리온 풍 모니터링 GUI. 검은 배경·주황/호박색·빨간 경보, 육각형 격자, 경고 띠, 3분할 판정 패널 같은 분위기만 참고한다.
- [확정] 원작 로고·상용 폰트·캐릭터 이미지·원작 화면을 그대로 옮기지 않는다 (공개 저장소). 무료 폰트와 직접 만든 아이콘을 쓴다.
- [미정] GUI 데이터 출처 (관리 API 경유 vs 직접 수집), 구현 기술
- [확정] 대시보드·수집기를 띄우면 외부에 공개하지 않는다 (`127.0.0.1` 또는 Tailscale IP).
- [확정] 알림용 웹후크·토큰은 `.env`에 둔다.
- [미정] 도구 (스크립트 + 알림 vs Prometheus/Grafana 등)
- [미정] 알림 채널
