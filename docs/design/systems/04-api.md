# 04. 관리 API (`area:api`)

서버 상태 확인·관리용 HTTP API.

## 규칙
- [아이디어] FastAPI로 상태 조회, 화이트리스트 관리, 백업 실행 등을 제공한다.
- [확정] 외부에 공개하지 않는다. `127.0.0.1` 또는 Tailscale IP로만 바인딩.
- [확정] RCON 명령을 만들 때 입력을 검증한다 (명령 주입 금지).
- [미정] 기능 범위
- [미정] 인증 방식
- [미정] 위치 (`api/` 폴더 [임시]), 실행 방식 (컨테이너 vs 호스트)
