# 접속 안내

친구 전용 마인크래프트 서버입니다.

## 필요한 것
- 마인크래프트 **자바판** 정품 계정 (온라인 모드라 정품만 접속 가능)
- 게임 버전: 26.3 (서버 버전에 맞춰야 접속됩니다)

## 접속 방법
1. 운영자에게 **마인크래프트 닉네임**을 알려주세요. 화이트리스트에 추가해야 접속할 수 있습니다.
2. 운영자에게 서버 주소(도메인:포트)를 받으세요. 공개 저장소라 여기에는 적지 않습니다.
3. 멀티플레이 → 서버 추가 → 받은 주소 입력 → 접속

## 접속이 안 될 때
- "화이트리스트에 없습니다": 운영자에게 닉네임을 다시 확인해주세요.
- "연결 시간 초과": 서버가 꺼져 있거나 주소가 바뀌었을 수 있습니다. 운영자에게 알려주세요.
- 버전 오류: 런처 설치 설정에서 26.3을 선택해주세요.
